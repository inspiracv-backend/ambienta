# Ambienta

Sistema multi-tenant para la gestión de cumplimiento ambiental de empresas industriales en Chile.

## Objetivo
Centralizar declaraciones ambientales (RETC, residuos peligrosos, Ley REP 20.920, etc.), alertar vencimientos y generar reportes de auditoría.

## Arquitectura
- **Frontend**: Next.js 14 (App Router)
- **Backend**: NestJS (microservicios)
- **Monorepo**: Turborepo + pnpm/npm workspaces
- **Base de datos**: PostgreSQL + Redis
- **Metodología**: Spec-Driven Development (SDD) con OpenSpec
